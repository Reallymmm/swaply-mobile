# Swaply Mobile

Мобильное приложение Swaply, платформы для обмена вещами без денег. Пользователь выкладывает вещь, пишет, что хочет получить взамен, и договаривается об обмене в чате.

**Стек:** Expo SDK 58, React Native 0.88, React 19, React Navigation.

Серверная часть лежит в отдельном репозитории: `swaply-admin`. Без запущенного сервера приложение работать не будет.

## Что умеет приложение

- **Регистрация по почте:** на почту приходит 6-значный код, после ввода кода создаётся аккаунт.
- **Лента** с поиском и фильтром по категориям, **избранное**.
- **Свои объявления:** создание, редактирование, фото, скрытие.
- **Чаты** с владельцами объявлений. Из чата можно открыть объявление, о котором идёт разговор.
- **Отзывы и рейтинг** продавцов.
- **Уведомления:** колокольчик в профиле открывает историю (новые сообщения, решения модерации).
- **Профиль:** фото, смена местоположения (города).
- **Блокировки:** заблокированный пользователь видит причину и может подать апелляцию.

Нижнее меню: Лента, Избранное, Добавить, Чаты, Профиль.

## Что нужно заранее

- Запущенный сервер из `swaply-admin` (порт 8000).
- Приложение **Expo Go** на телефоне. Его версия должна поддерживать Expo SDK 58.
- Телефон и компьютер в одной Wi-Fi сети (кроме режима tunnel, см. ниже).
- Для запуска через Docker: [Docker Desktop](https://www.docker.com/products/docker-desktop/). Для запуска без Docker: [Node.js](https://nodejs.org/) (в Docker-образе используется версия 22).

## Шаг 1. Укажи адрес сервера

Открой `src/config.js` и впиши IP компьютера, где запущен сервер, и порт 8000:

```js
export const API_URL = "http://192.168.0.105:8000";
```

IP компьютера смотри командой `ipconfig` (строка «IPv4-адрес» твоей Wi-Fi сети).

## Шаг 2. Запусти приложение

### Вариант А: через Docker (рекомендуется)

1. Создай файл `.env` из примера и впиши в `HOST_IP` тот же IP компьютера, что и в `config.js`:

   ```
   copy .env.example .env
   ```

   Без `HOST_IP` Docker не запустится и напомнит об этом.

2. Запусти:

   ```
   docker compose up --build
   ```

3. Когда в окне появится QR-код, отсканируй его в Expo Go (на Android через кнопку «Scan QR code» внутри Expo Go, на iPhone камерой).

Docker запускает Expo в режиме `--lan`, поэтому телефон должен быть в одной сети с компьютером. Брандмауэр Windows должен пропускать порт **8081**.

Папка `src` и файл `App.js` подключены к контейнеру, поэтому правки в коде подхватываются на лету без пересборки. Если менял `package.json`, запусти ещё раз `docker compose up --build`.

Остановить: `Ctrl+C`, затем `docker compose down`.

### Вариант Б: без Docker (Windows)

1. Один раз дважды щёлкни `setup.bat` и дождись надписи `DONE`. Он ставит все пакеты.
2. Для запуска дважды щёлкни `start.bat`. Появится QR-код, отсканируй его в Expo Go.

Скрипт запускает Expo в режиме **tunnel**: так приложение открывается, даже если телефон не в одной сети с компьютером (но API-сервер всё равно должен быть доступен по адресу из `config.js`). Если Expo спросит про установку `@expo/ngrok`, ответь `y` и нажми Enter.

То же самое из командной строки:

```
npm install
npm start
```

## Регистрация и вход

1. На экране входа выбери «Регистрация», введи имя, email и пароль (не короче 6 символов) и нажми «Получить код на почту».
2. Введи 6 цифр из письма. Код действует 10 минут, ошибиться можно 5 раз, новый код можно запросить раз в минуту.
3. Если на сервере не настроена почта (Brevo), письма не уходят, а код печатается в логах сервера: `docker compose logs -f web` в папке `swaply-admin`.

## Структура проекта

```
swaply-mobile/
  App.js               - точка входа: навигация и экраны
  index.js             - регистрация приложения в Expo
  app.json             - название, иконка и заставка
  assets/              - иконки и логотип
  src/
    config.js          - адрес сервера (API_URL)
    api.js             - все запросы к серверу
    notifications.js   - опрос уведомлений и всплывающая плашка
    theme.js           - цвета и размеры
    utils.js           - форматирование дат, рейтинга и т.п.
    navigation/        - нижнее меню (Tabs.js)
    components/        - кнопка, аватар, фото, карточка объявления
    screens/           - экраны: вход, лента, объявление, чат,
                         профиль, уведомления, отзывы и другие
  Dockerfile           - образ для запуска Expo
  docker-compose.yml   - запуск Expo одной командой
  setup.bat, start.bat - запуск без Docker (Windows)
```

## Частые проблемы

| Проблема | Решение |
|---|---|
| «Нет связи с сервером» | Проверь, что сервер запущен, адрес в `src/config.js` верный (IP из `ipconfig`) и телефон в той же сети. Брандмауэр Windows должен пропускать порты 8000 (сервер) и 8081 (Expo) |
| Docker пишет про `HOST_IP` | Создай файл `.env` рядом с `docker-compose.yml` и впиши `HOST_IP=твой_IP` |
| QR-код не открывается в Expo Go | Убедись, что телефон и компьютер в одной Wi-Fi сети. Если сети разные, запускай без Docker через `start.bat` (tunnel) |
| Expo Go пишет, что проект несовместим | Обнови Expo Go в магазине приложений: проект использует Expo SDK 58 |
| Код с почты не приходит | Загляни в «Спам». Если почта на сервере не настроена, код смотри в логах сервера (см. раздел «Регистрация и вход») |
| После смены IP компьютера всё перестало работать | Поменяй IP в `src/config.js` и в `.env` (`HOST_IP`) и перезапусти Expo |

## Безопасность

Файл `.env` в Git не попадает (он в `.gitignore`). В `src/config.js` лежит только адрес сервера, секретов в нём нет. Ключи и пароли хранятся на стороне сервера, в `swaply-admin/backend/.env`.
